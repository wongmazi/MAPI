# 新人总体说明

本仓库用于沉淀 CAD / Office / Midas Civil 等工具的自动化想法与原型（命令流、脚本或插件）。

## 目标

- 让没有代码经验的新成员也能快速理解“自动化能做什么”
- 将想法逐步转化为可复现的流程或脚本
- 形成可协作、可扩展的知识与原型库

## 建议学习路径（零代码友好）

1. **先理解流程**：把手工操作拆成清晰步骤（输入 → 处理 → 输出）。
2. **再做无代码自动化**：模板、批处理、宏录制等。
3. **逐步进入低代码**：只修改参数与关键几行脚本。
4. **形成原型**：写出“目标/输入/输出/流程/限制”的原型说明。

## 示例想法清单（可挑选落地）

- CAD：图层统一、批量改名、出图模板化
- Office：Excel 报表模板、Word 批量生成、数据清洗
- Midas Civil：批量建模参数、结果导出、命令流复用

## 如何贡献

- 为一个想法创建一份说明文档
- 补充示例数据或截图
- 逐步将说明升级为脚本/命令流
