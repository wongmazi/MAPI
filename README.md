# MAPI project

一个用于沉淀自动化脚本/命令流想法与实践的轻量仓库。当前版本提供了：

- 项目定位与目录说明
- 新人上手的学习路径与建议
- 示例想法清单（可逐步扩展为脚本或插件）

## 目录结构

```
.
├── README.md
└── docs
    ├── overview.md        # 面向新人的整体说明
    ├── quickstart.md      # 快速上手指引
    └── faq.md             # 常见问题
```

## 你可以从这里开始

1. 阅读新人的总体介绍与学习建议：`docs/overview.md`
2. 按步骤完成仓库快速上手：`docs/quickstart.md`
3. 在 `docs/overview.md` 的“示例想法清单”里挑一个点，逐步落地为脚本/命令流/插件原型
4. 查看常见问题：`docs/faq.md`
